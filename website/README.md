# Dad’s Typing website

A one-page static site: `index.html` plus `img/`. No build step.

- Preview locally: `python3 -m http.server 8088` in this folder, then open http://localhost:8088
- Host: upload this folder as-is to any static host (Render static site, Netlify, Vercel, GitHub Pages, Cloudflare Pages). Publish directory: `website`.
- Fonts load from Google Fonts (Fraunces for headlines, DM Sans for everything else).
- Illustrations come from the presentation kit; partner logos are in `img/logos/`.
